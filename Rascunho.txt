Caso o minikube não suba por falta de memória.
- Limpe tudo
minikube delete --all --purge
docker system prune -a --volumes

- Rode com memória real
minikube start --driver=docker --cpus=4 --memory=8192 --disk-size=40g

- Comando para habilitar ver os containers no docker
minikube ssh -- df -h
minikube ssh -- free -m







Criar o namespace
- kubectl create namespace plataforma-educacional

Se tiver problemas no deploy do minikube...
1) Melhorar a cache local do minikube
- minikube config set container-runtime docker
- minikube config set memory 8192
- minikube config set cpus 4
- minikube config set disk-size 40g
2) apagar minikube
- minikube delete
3) Iniciar o minikube com configuração específica
- minikube start --driver=docker --cpus=4 --memory=8192 --disk-size=40g

Configuração do minikube

== Instalação
choco install minikube -y
choco install kubernetes-cli -y

== Iniciar o cluster
minikube start --driver=docker


== verificar nodes
kubectl get nodes

== Criar namespace
kubectl apply -f k8s/

== Ver os PODs
kubectl get all -n plataforma-educacional

== Acessar o front
minikube service frontend -n plataforma-educacional
